1. 回答使用中文
2. 增加或修改功能时请确认是否需要使用到后端
3. front 端代码请保持与 back 端代码的一致性
4. 前端代码存储在 `front` 目录下, 后端代码存储在 `back` 目录下, 后期工作需要使用的rag模型代码存储在 `LightRAG-main` 目录下
5. 完成代码后请使用错误识别机制检查代码是否有错误，若有错误请及时修复
6. PowerShell 不支持 && 和 head
7. 前端代码中使用的 API 基础 URL 为 `http://localhost:3001/api`, 后端代码中使用的 API 基础 URL 为 `http://localhost:3001/api`
8. 无需使用 'npm run build' 重构前端代码
